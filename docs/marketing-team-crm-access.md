# 마케팅팀 CRM 협업·권한 운영 절차

작성일: 2026-08-29

## 결론

CRM은 사용자별 독립 로그인 세션을 사용하므로 마케팅팀이 동시에 접속해 사용할 수 있다. 단, 현재 역할은 `admin`, `staff`, `branch_admin`, `user` 네 가지뿐이다. 마케팅 전용 읽기/캠페인 역할은 아직 없으므로, 단순 조회·회원 관리 목적에 따라 가장 낮은 기존 권한을 부여해야 한다.

## 초기 권한 부여 절차

1. 대상 직원이 자신의 구글 계정으로 `https://membership.nops.kr/admin`에 로그인한다.
2. 처음 로그인한 계정은 기본 `user` 역할로 생성되며 관리자 화면에 접근할 수 없다.
3. 슈퍼 어드민이 **관리자 → 권한 관리**에서 해당 계정을 이름 또는 이메일로 검색한다.
4. 업무 범위에 맞는 역할을 선택한다. `branch_admin`일 경우 지점 코드를 함께 지정한다.
5. 직원은 로그아웃·재로그인 후 권한이 적용됐는지 확인한다.

## 현재 역할과 권장 배정

| 역할 | 현재 범위 | 마케팅팀 권장 여부 |
|---|---|---|
| `admin` | 전체 기능과 사용자 권한 변경 | 불가피한 1~2명 시스템 관리자에게만 부여 |
| `staff` | 대시보드·회원·쿠폰·데이터 분석 접근 | 본사 CRM 운영 책임자에 한해 제한적으로 부여 |
| `branch_admin` | 회원·쿠폰 관리 | 특정 매장 마케팅 담당자에게만, 지점 코드 지정 후 부여 |
| `user` | 관리자 화면 접근 불가 | 대기 또는 고객 계정 |

## 동시 접속 운영 원칙

각 직원은 반드시 자신의 계정으로 로그인해야 하며, 하나의 관리자 계정을 공동 사용하면 안 된다. 동시 접속 자체는 가능하지만, 같은 회원·쿠폰·캠페인을 동시에 수정할 경우 마지막 저장이 앞선 변경을 덮어쓸 수 있다. 아래처럼 책임을 나눈다.

| 업무 | 담당 원칙 | 승인/검토 |
|---|---|---|
| 회원·쿠폰 조회 | 마케팅팀 조회 담당 | 수정 불필요 |
| 쿠폰 수동 발급·사용 처리 | 지정 운영자 1명 | 일일 발급·사용 이력 검토 |
| 캠페인 문구·대상 파일 준비 | 마케팅팀 1명 | 발송 전 운영 관리자 검토 |
| SMS·브랜드 메시지 실제 발송 | 지정 발송 책임자 1명 | 대상 수·문구·080·발송 시간 이중 확인 |
| 사용자 역할 변경 | 슈퍼 어드민 | 월 1회 권한 목록 점검 |

## 현재 구조의 한계와 후속 개선

현재 `staff`는 회원·쿠폰 관리 권한을 함께 받으므로, 캠페인 성과만 보는 마케팅팀에게는 과도할 수 있다. 마케팅팀이 상시 협업해야 한다면 다음의 전용 `marketing_manager` 역할을 별도로 구현해야 한다.

| 허용 | 차단 |
|---|---|
| 분석 대시보드·캠페인 대상 수·발송 이력 조회 | 사용자 권한 변경 |
| 승인된 캠페인 초안 작성·검토 요청 | 회원 원본 CSV 내보내기 |
| 캠페인 발송 결과 확인 | 쿠폰 임의 발급·사용 처리 |
| 집계된 고객 세그먼트 조회 | 전체 고객 연락처·생년월일 열람 |

전용 역할이 구현되기 전에는 `staff` 권한을 최소 인원에만 주고, 관리자 계정 공유·개인정보 파일 외부 반출·무단 발송을 금지한다.
