# SOLAPI 콘솔 MMS 등록·발송 가이드

대상 캠페인: NOPS 9월 신메뉴 베네핏 스테이크 콤보 10% 할인 쿠폰  
작성일: 2026-09-02  
범위: SOLAPI **웹 콘솔**에서 이미지·본문·수신자·링크를 등록하고 테스트 및 예약 발송하는 절차

> 이 가이드는 메시지 발송 절차만 다룬다. SOLAPI 콘솔은 CRM 쿠폰을 자동으로 발급하지 않는다. 고객에게 ‘쿠폰이 발급되었습니다’라고 안내하려면, 쿠폰을 먼저 CRM에서 별도 캠페인 쿠폰으로 발급하고 대상 파일을 확정해야 한다.

## 1. 발송 방식 결정

이미지를 붙이면 LMS가 아니라 **MMS**다. SOLAPI는 이미지가 첨부되면 MMS로 자동 분류한다. MMS는 JPG 이미지 1장과 최대 2,000바이트의 본문을 보낼 수 있다.[1]

| 구분 | LMS | MMS |
|---|---|---|
| 이미지 | 불가 | 가능 |
| 본문 | 최대 2,000바이트 | 최대 2,000바이트 |
| 신메뉴 음식 사진 | URL로만 안내 | 본문과 함께 바로 노출 |
| 이번 캠페인 권장 | 이미지 제작 전 임시안 | **권장안** |

MMS에는 카카오 브랜드 메시지처럼 구조화된 버튼이 없다. 카카오 채널·쿠폰 확인 링크는 **본문에 일반 URL 텍스트로 삽입**한다. 일부 단말기의 기본 문자 앱이 URL을 탭 가능한 링크로 표시하지만, 버튼 모양·표시는 통신사와 단말기 환경에 따라 달라질 수 있다.

## 2. 발송 전 준비물

| 준비물 | 기준 | 책임자 |
|---|---|---|
| 발신번호 | SOLAPI에 사전 등록·인증된 NOPS 번호 | 운영 담당자 |
| MMS 이미지 | JPG, 200KB 이하, 가로 1,500px 이하, 세로 1,440px 이하 | 디자인/마케팅 |
| 대상 파일 | 활성·SMS 마케팅 동의·수신거부 제외·이번 캠페인 미발송 회원만 | CRM 운영자 |
| 쿠폰 | 기존 가입 10%가 아닌 `sep_combo_2026` 별도 쿠폰을 회원당 1회 발급 | CRM 운영자 |
| 쿠폰 확인 링크 | 이미 발급된 쿠폰을 확인하는 `/mypage` URL | CRM 운영자 |
| 카카오 채널 URL | 카카오 채널 관리자센터에서 복사한 실제 채널 홈 또는 친구추가 URL | 마케팅팀 |
| 행사 조건 | 사용 기간·적용 메뉴·사용 가능 지점·타 할인 중복 여부 | 매장/마케팅 책임자 |

현재 CRM에는 9월 이벤트 쿠폰 발급 기능이 아직 구현돼 있지 않다. 따라서 이 문서는 **발송 준비·테스트용**이며, 쿠폰 발급·발송 이력 기능을 만들기 전 대량 실발송에는 사용하면 안 된다.

## 3. MMS 이미지 만들기

### 3-1. 이미지 내용

음식 사진 1장과 혜택만 넣는다. 기획 슬라이드의 화살표·경쟁 채널 예시·내부 회원 수는 고객용 이미지에 넣지 않는다.

권장 문구는 아래와 같다.

> NOPS 9월 신메뉴 출시  
> 베네핏 스테이크 콤보  
> **멤버십 감사 10% 할인 쿠폰**  
> 사용 기간: **[YYYY.MM.DD까지]**

### 3-2. 파일 검수

1. JPG 형식으로 내보낸다. PNG·GIF·PDF는 MMS 이미지로 사용하지 않는다.
2. 파일 크기를 **200KB 이하**로 압축한다.
3. 이미지 크기를 가로 1,500px 이하·세로 1,440px 이하로 맞춘다.
4. 이미지 안에는 개인 이름, 쿠폰 코드, 고객별 만료일을 넣지 않는다. 모든 고객에게 같은 이미지를 쓴다.
5. 혜택명·메뉴 범위·기간이 본문과 동일한지 확인한다.

## 4. SOLAPI 콘솔에서 이미지·본문 등록

1. [SOLAPI 콘솔](https://console.solapi.com/login)에 로그인한다.
2. 좌측 메뉴에서 **메시지 → 메시지 보내기**로 이동한 뒤 **문자 메시지** 탭을 연다.[2]
3. 발신번호에서 SOLAPI에 사전 등록된 NOPS 발신번호를 선택한다. 등록되지 않은 번호는 MMS를 보낼 수 없다.[2]
4. 수신자 영역에는 처음에는 **내부 테스트 번호 1~3개만** 넣는다. 본발송 목록은 테스트가 끝난 뒤에 올린다.
5. 본문 작성 영역에서 다음 문구를 입력한다. 이미지 첨부 영역 또는 이미지 추가 버튼에서 검수한 JPG 파일을 업로드한다. 이미지가 붙으면 SOLAPI가 MMS로 자동 분류한다.[2]
6. `광고 메시지 여부`를 선택한다. 080 번호가 별도로 없다면 SOLAPI 콘솔에서 제공하는 무료 수신거부 번호 사용을 선택한다. **본문에 080을 수동으로 한 번 더 입력하기 전에 미리보기에서 중복 삽입 여부를 확인**한다.[2]
7. 카카오 채널 URL은 실제 채널 관리자센터에서 복사한 URL만 넣는다. 현재 CRM에는 채널 URL이 저장되어 있지 않으므로 임의 주소를 쓰면 안 된다.

## 5. 붙여넣기용 MMS 본문

아래 대괄호 값은 전송 직전에 확정한다.

```text
(광고)[NOPS] #{이름}님, 9월 신메뉴 베네핏 스테이크 콤보 10% 할인 쿠폰이 발급되었습니다.

쿠폰 확인: https://membership.nops.kr/mypage?utm_source=sms&utm_medium=mms&utm_campaign=sep_combo_2026
사용 기간: [YYYY.MM.DD]까지
적용 메뉴: [베네핏 스테이크 콤보 전 메뉴 / 확정 문구]
문의: 02-597-4030
NOPS 카카오톡 채널: [실제 채널 URL]
```

`#{이름}`은 SOLAPI의 개인화 변수다. 수신자 파일의 첫 행 열 제목이 `이름`이어야 치환할 수 있다.[2]

> 080 수신거부 번호는 콘솔의 광고 메시지 설정으로 삽입·검수하는 방식을 우선한다. 본문에 `무료수신거부 080-500-4233`을 직접 넣는 방식과 콘솔 자동 삽입을 동시에 적용하면 중복 노출될 수 있다.

## 6. 수신자 엑셀 파일 준비

파일은 XLSX로 만들고 첫 행을 열 제목으로 둔다. 전화번호 열은 Excel에서 지수 표기나 선행 0이 사라지지 않도록 **텍스트 형식**으로 저장한다.

| 이름 | 수신번호 | 쿠폰확인URL | 쿠폰코드 |
|---|---|---|---|
| 홍길동 | 01012345678 | https://membership.nops.kr/mypage?... | ABCD1234 |

이번 문구에서 실제로 쓰는 열은 `이름`, `수신번호`이다. 개인 쿠폰 코드까지 보낼 경우에만 `#{쿠폰코드}` 변수를 본문에 추가한다. 쿠폰 코드를 URL 쿼리 값에 평문으로 넣지 않는다.

SOLAPI 콘솔 수신자 영역에서 **엑셀 업로드**를 선택하고, 파일·시트·범위를 확인한다. 첫 행은 필드명으로 인식되므로 수신자에게 발송되지 않는다.[2]

본발송 파일에는 아래 고객을 넣지 않는다.

1. `status`가 `active`가 아닌 회원
2. SMS 마케팅 동의가 없는 회원
3. SOLAPI 수신거부 목록 또는 내부 발송 차단 목록의 회원
4. `sep_combo_2026` 캠페인 쿠폰이 없는 회원
5. 같은 캠페인 SMS를 이미 받은 회원

## 7. 테스트 발송

1. 운영자·마케팅 담당자·아이폰 또는 안드로이드 테스트 번호 등 **1~3명**만 수신자로 넣는다.
2. **전송/예약 준비**를 눌러 유형이 `MMS`로 표시되는지, 발신번호·수신자 수·예상 차감액·광고성 표시·080 표기를 확인한다.[2]
3. 테스트 전송을 실행한다. 테스트도 비용 또는 포인트가 차감된다.[2]
4. 실제 단말기에서 아래를 확인한다.

| 확인 항목 | 통과 기준 |
|---|---|
| 이미지 | 깨짐 없이 표시되며 음식·혜택·기간을 읽을 수 있음 |
| 본문 | 이름·기간·메뉴 범위가 정확함 |
| 쿠폰 링크 | 로그인/OTP 후 실제 고객의 쿠폰함으로 이동 |
| 카카오 링크 | 실제 NOPS 채널 홈 또는 친구추가 화면으로 이동 |
| 광고 고지 | `(광고)`, 문의처, 무료수신거부가 한 번만 표시됨 |
| 쿠폰 | 테스트 대상에게 이미 발급된 이벤트 쿠폰이 실제로 존재 |

## 8. 본발송 예약

테스트가 통과한 뒤에만 필터링 완료된 본발송 파일을 업로드한다.

1. 중복 번호·수신거부·캠페인 발송 이력 제외 여부를 CRM에서 다시 확인한다.
2. 수신자 수가 예상치와 일치하는지 확인한다. 멤버십 약 2,600명 전체가 아니라 SMS 동의 등 필터 적용 후 수가 기준이다.
3. **전송/예약 준비**에서 메시지 유형, 이미지, 수신자 수, 비용, 광고성 고지, 예약 일시를 재확인한다.
4. 광고성 MMS는 **08:00~20:50 KST** 사이로 예약한다.
5. 발송 후 SOLAPI 전송요청내역에서 접수 성공·실패 건을 확인한다. SOLAPI 접수 성공은 최종 단말 도달과 동일하지 않을 수 있으므로 실패 사유와 전송 결과를 별도로 보관한다.

## 9. 가장 중요한 운영 오류 5가지

| 오류 | 왜 문제인가 | 방지 방식 |
|---|---|---|
| 쿠폰 발급 전 MMS 발송 | 고객이 쿠폰함에 들어가도 쿠폰이 없음 | 쿠폰 발급·대상 파일 확정 후 발송 |
| 기존 가입 10% 쿠폰 재활용 | 회원당 1회 가입 혜택 정책 훼손 | 별도 이벤트 쿠폰·발급 키 사용 |
| 2,600명 전체 발송 | SMS 동의·수신거부 조건 위반 가능 | 활성·동의·차단 제외 필터 적용 |
| 080 번호 이중 표기 | 콘솔 자동 삽입과 본문 수동 입력이 겹침 | 미리보기에서 하나만 남겼는지 확인 |
| 임시 채널 URL 사용 | 고객이 잘못된 페이지로 이동 | 채널 관리자센터에서 복사한 실제 URL 사용 |
