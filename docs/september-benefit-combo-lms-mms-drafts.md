# 9월 베네핏 콤보 10% 쿠폰: LMS·MMS 발송 초안

작성일: 2026-09-02  
대상: 멤버십 회원 중 SMS 마케팅 수신 동의·활성 상태·수신거부 미등록 고객

## 먼저 결정할 발송 형식

**이미지를 첨부하면 LMS가 아니라 MMS다.** LMS는 본문과 URL만 포함하는 장문 문자이고, MMS는 이미지와 본문을 함께 보내는 사진 문자다. SOLAPI 기준 MMS 이미지는 JPG, 최대 200KB여야 하며 `imageId`를 지정해 발송한다.[1]

| 형식 | 추천 상황 | 장점 | 주의점 |
|---|---|---|---|
| LMS | 메뉴 사진 없이 쿠폰·기간·링크를 명확히 전달할 때 | 제작 속도가 빠르고 본문 수정이 쉬움 | 이미지 노출 없음 |
| MMS | 콤보 메뉴 사진이 구매 의사결정에 중요한 신메뉴 출시 캠페인 | 음식 사진과 혜택을 한 화면에 전달 | JPG 200KB 이하 원본 준비 및 이미지 ID 등록 필요 |
| RCS 이미지 | 버튼·브랜드 카드가 꼭 필요하고 별도 템플릿 준비가 가능한 경우 | 풍부한 인터랙션 | 현재 NOPS에 RCS 템플릿·발신 브랜드 설정 없음 |

이번 신메뉴 출시는 음식 사진이 핵심이므로 **MMS를 우선 권장**한다. 이미지 제작이 늦어지거나 메뉴·조건이 변동될 수 있으면 LMS로 먼저 발송할 수 있다.

## 발송 대상 기준

약 2,600명 전체가 SMS 발송 대상은 아니다. 현재 집계상 활성 회원 중 SMS 마케팅 동의자는 **2,471명**이다. 쿠폰을 모든 적격 회원에게 발급하더라도, SMS는 아래 조건을 모두 만족한 회원에게만 보낸다.

1. `status = active`
2. `marketingConsent = true`
3. SOLAPI 수신거부 목록 및 내부 차단 목록에 없음
4. `sep_combo_2026` 캠페인 SMS를 아직 받지 않음
5. 발급된 캠페인 쿠폰이 활성 상태이고 사용·만료되지 않음

쿠폰은 기존 가입 기념 10% 할인 쿠폰의 재발급이 아니라 **별도 이벤트 쿠폰**으로 발급한다. 발급 키는 `sep_combo_2026_v1`처럼 구분하고 회원당 1회로 제한한다.

## 쿠폰·정보 확인 링크

이벤트 수령 페이지는 아직 구현되지 않았으므로, 이미 이벤트 쿠폰이 발급된 고객에게는 현재 운영 중인 쿠폰함 링크를 사용한다.

```text
https://membership.nops.kr/mypage?utm_source=sms&utm_medium=lms&utm_campaign=sep_combo_2026
```

이 링크에서 고객은 본인 인증 후 쿠폰 코드·만료일을 확인한다. **아직 쿠폰을 발급하지 않은 고객에게 이 링크를 보내면 새 쿠폰을 받을 수 없다.** 미발급 회원을 링크에서 인증 후 발급하려면 이벤트 페이지를 별도로 구현해야 한다.

카카오톡 채널 링크는 채널 운영 주소를 확정한 뒤에만 추가한다. 현재 정확한 NOPS 카카오 채널 URL이 시스템에 저장되어 있지 않으므로 아래 자리에 실제 링크를 넣는다.

```text
[카카오톡 NOPS 채널 링크]
```

## MMS 초안 — 이미지 포함 권장안

### 이미지 안의 문구

> **NOPS 9월 신메뉴 출시**  
> 베네핏 스테이크 콤보  
> **멤버십 감사 10% 할인 쿠폰**  
> 사용 기간: **[YYYY.MM.DD까지]**

이미지에는 음식 사진 1장, NOPS 로고, 혜택명, 행사 종료일만 넣는다. ‘전 메뉴’와 ‘콤보 메뉴’ 중 어느 범위인지 확정하지 않은 표현, 개인 쿠폰 코드, 고객명은 이미지에 넣지 않는다.

### MMS 본문

> (광고)[NOPS] [고객명]님, 9월 신메뉴 **베네핏 스테이크 콤보 10% 할인 쿠폰**이 발급되었습니다.
>
> 쿠폰 확인: https://membership.nops.kr/mypage?utm_source=sms&utm_medium=mms&utm_campaign=sep_combo_2026
> 사용 기간: [YYYY.MM.DD]까지
> 적용 메뉴: [베네핏 스테이크 콤보 전 메뉴 / 확정 문구]
> 문의: 02-597-4030
> NOPS 카카오톡 채널: [확정 채널 링크]
> 무료수신거부 080-500-4233

## 짧은 LMS 초안 — 링크 우선형

> (광고)[NOPS] [고객명]님, 9월 신메뉴 베네핏 스테이크 콤보 10% 할인 쿠폰이 발급되었습니다. 쿠폰 확인: https://membership.nops.kr/mypage?utm_source=sms&utm_medium=lms&utm_campaign=sep_combo_2026 / 사용기간 [YYYY.MM.DD]까지 / 문의 02-597-4030 / 무료수신거부 080-500-4233

이 문안은 길이와 한글 바이트 수에 따라 LMS로 발송될 가능성이 높다. 90바이트 이하만 SMS로 자동 분류되므로, 실제 발송 전 SOLAPI 미리보기에서 형식을 확인한다.[1]

## 발송 전 확정값

| 항목 | 현재 상태 | 발송 전 조치 |
|---|---|---|
| 할인 적용 메뉴 | 미확정 | `베네핏 스테이크 콤보 전 메뉴`인지 품목 제한이 있는지 확정 |
| 쿠폰 사용 기간 | 미확정 | 날짜 또는 발급일 기준 유효기간 확정 |
| 쿠폰 중복 할인 | 미확정 | 타 쿠폰·제휴·직원 할인 중복 가능 여부 명시 |
| 발송 이미지 | 미제작 | 음식 사진 기반 JPG 200KB 이하 제작·SOLAPI 이미지 등록 |
| 카카오 채널 URL | 시스템 미보관 | 실제 채널 링크 확정 |
| 이벤트 쿠폰 | 미구현 | 별도 템플릿·발급 키·발송 이력 구현 |
| 발송 시간 | 필수 | 광고성 MMS/LMS는 08:00~20:50 KST 예약 |

## 운영상 금지 사항

1. 2,600명 전체에 무차별 SMS를 발송하지 않는다. SMS 동의·활성·수신거부 필터를 적용한다.
2. 쿠폰 발급 전에 ‘쿠폰 발급 완료’ 문구와 쿠폰함 링크를 보내지 않는다.
3. 기존 가입 기념 10% 쿠폰을 새 캠페인 쿠폰으로 재사용하거나 재발급하지 않는다.
4. 고객 이름·쿠폰 코드·개인 링크가 포함된 이미지를 공용으로 재사용하지 않는다.
5. 20:50~08:00 KST에는 예약 발송하지 않는다.
