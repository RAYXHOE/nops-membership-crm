# NOPS 멤버십 SOLAPI 알림톡 승인용 템플릿 초안

작성일: 2026-08-25 KST  
발신 프로필: NOPS 카카오톡 채널

## 등록 원칙

각 템플릿은 이미 발생한 가입, 쿠폰 발급, 적립금 만료와 같이 고객 멤버십 이용에 필요한 **정보성 안내**만 전달합니다. 등록 시 아래 `#{...}` 변수명과 줄바꿈을 그대로 유지해야 현재 코드와 일치합니다.

| 코드 환경변수 | SOLAPI 등록 목적 | 발송 시점 |
|---|---|---|
| `SOLAPI_TEMPLATE_WELCOME` | 가입 완료 및 쿠폰 발급 | 가입 직후 |
| `SOLAPI_TEMPLATE_BIRTHDAY` | 생일 쿠폰 발급 | 생일 쿠폰 발급 시 |
| `SOLAPI_TEMPLATE_ANNIVERSARY` | 결혼기념일 쿠폰 발급 | 기념일 쿠폰 발급 시 |
| `SOLAPI_TEMPLATE_CORKAGE` | 콜키지 프리 쿠폰 재발급 | 재발급 시 |
| `SOLAPI_TEMPLATE_POINTS_EXPIRY` | 적립금 만료 D-30 안내 | 만료 30일 전 |

## 1. 가입 완료 및 쿠폰 발급

**권장 템플릿명:** `NOPS 멤버십 가입 완료`

```text
안녕하세요, #{이름}님.
NOPS 멤버십 가입이 완료되었습니다.

발급된 쿠폰
#{쿠폰목록}

쿠폰별 유효기간과 사용 가능 여부는 마이페이지에서 확인해 주세요.
#{링크}

Mr. 놉스 올림
```

**등록 변수:** `#{이름}`, `#{쿠폰목록}`, `#{링크}`

## 2. 생일 쿠폰 발급

**권장 템플릿명:** `NOPS 생일 쿠폰 발급`

```text

쿠폰번호: #{쿠폰코드}
유효기간: #{만료일}

마이페이지에서 쿠폰을 확인해 주세요.
#{링크}

Mr. 놉스 올림
```

**등록 변수:** `#{이름}`, `#{쿠폰명}`, `#{할인율}`, `#{쿠폰코드}`, `#{만료일}`, `#{링크}`


## SOLAPI 등록 후 적용 절차

1. 위 다섯 템플릿을 정보성 알림톡으로 등록하고 승인을 받습니다.
2. 승인된 템플릿 ID를 각각 대응하는 환경변수에 저장합니다.
3. 승인 ID 등록 후 관리자 계정으로 각 이벤트의 시험 발송을 한 건씩 수행합니다.
4. `alimtalk_logs`에서 성공 상태와 수신 단말의 실제 문구를 함께 확인합니다.

승인 전에는 생일·결혼기념일·콜키지 재발급·적립금 만료 이벤트가 용도가 다른 템플릿으로 발송되지 않도록 코드가 차단합니다.

## 브랜드 템플릿 운영 조건

콜키지 재발급과 결혼기념일 쿠폰은 알림톡 템플릿과 다른 **브랜드 템플릿**으로 관리한다. 브랜드 메시지는 `brandTemplateId`를 사용하므로 알림톡의 `templateId`로 발송할 수 없다.

브랜드 메시지는 광고성 메시지로 취급한다. 기본 발송 대상은 카카오톡 채널을 추가한 고객이며, 채널 친구가 아닌 마케팅 수신 동의자에게 확대 발송하려면 카카오 승인·채널 친구 5만 명·080 수신거부 번호 등의 별도 조건이 필요하다. 또한 광고 메시지는 20:50부터 다음 날 08:00까지 발송하면 안 된다. 따라서 CRM 연결 전에는 **마케팅 동의 여부, 채널 친구/확장 발송 권한, 080 수신거부 문구, 발송 시간 제한**을 서버에서 모두 검증해야 한다.
