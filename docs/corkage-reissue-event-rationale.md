# 콜키지 프리 쿠폰 사용 후 30일 재발급 이벤트 명분 초안

## 1. 현재 대상 현황

기준일 **2026-09-10 KST**에 콜키지 프리 쿠폰을 사용한 지 정확히 30일이 지난 고객은 **0명**입니다. 따라서 오늘 자동 재발급 및 안내 메시지 대상도 **0명**입니다.

자동화 대상은 단순히 과거 콜키지 쿠폰을 사용한 모든 고객이 아닙니다. 사용 완료일이 정확히 30일 전인 쿠폰을 기준으로 회원을 중복 제거한 뒤, 활성 회원만 포함하며 당일 활성 콜키지 프리 쿠폰을 이미 재발급받은 회원은 제외합니다.

| 구분 | 현재 수 | 산정 기준 |
|---|---:|---|
| 30일 전 사용 완료 쿠폰 | 0건 | 2026-08-11 KST 00:00~23:59 사용 완료분 |
| 중복 제거한 사용 회원 | 0명 | 동일 회원의 복수 사용 이력은 1명으로 계산 |
| 비활성·존재하지 않는 회원 제외 | 0명 | 30일 전 사용 회원 중 활성 조건 미충족 |
| 당일 재발급 완료로 제외 | 0명 | 오늘 활성 콜키지 프리 쿠폰이 이미 발급된 회원 |
| 오늘 재발급 가능 회원 | 0명 | 활성 회원, 당일 재발급 미완료 조건 |
| 최종 대상 중 전화번호 미보유 | 0명 | SMS 발송 적격성 추가 확인 항목 |
| 당일 안내 가능 회원 | 0명 | 재발급 완료 후 동의·발송 채널 요건을 충족한 회원 |

## 2. 이벤트 운영 명분

### 내부 승인용 문구

> **콜키지 프리 이용 감사 및 재방문 편의 제공 프로그램**
>
> NOPS는 콜키지 프리 혜택을 이용한 멤버십 고객에게 이용 감사의 뜻을 전하고, 다음 방문 시 동일한 혜택을 다시 확인할 수 있도록 사용 완료 후 30일에 콜키지 프리 쿠폰을 재발급합니다. 즉시 재발급이 아니라 30일의 간격을 두어 사용 경험 직후의 과도한 반복 혜택 인식을 줄이고, 고객의 다음 방문 시점에 맞춘 관계 유지 혜택으로 운영합니다.
>
> 재발급은 활성 회원을 대상으로 회원당 해당 사용 이력에 대해 1회만 처리하며, 재발급 쿠폰은 발급일 기준 365일 동안 사용할 수 있습니다. 쿠폰 발급과 안내 메시지는 분리 관리해, 쿠폰이 실제로 생성된 고객에게만 안내합니다.

### 고객 안내용 핵심 메시지

> 콜키지 프리 혜택을 이용해 주셔서 감사합니다. 다음 방문에도 혜택을 확인하실 수 있도록 콜키지 프리 쿠폰을 다시 준비했습니다.

## 3. 채널별 발송 초안

발급 대상이 생긴 뒤에만 사용합니다. 메시지에 ‘발급되었습니다’라는 표현을 쓸 경우, 해당 고객의 쿠폰 생성 성공을 먼저 확인해야 합니다.

### SMS/LMS 초안

```text
(광고)[NOPS] 콜키지 프리 쿠폰 재발급

#{이름}님, 콜키지 프리 쿠폰을 이용해 주셔서 감사합니다.
다음 방문을 위해 콜키지 프리 쿠폰이 다시 발급되었습니다.

쿠폰 확인: https://membership.nops.kr/mypage
사용 기간: [쿠폰 만료일]까지
문의: 02-597-4030
무료수신거부: 080-500-4233
```

SMS는 활성 상태이면서 SMS 마케팅 수신 동의가 있고, 수신거부 목록에서 제외된 회원에게만 발송합니다. 광고성 SMS는 08:00~20:50 KST에만 예약하며, 자정 쿠폰 재발급과 별도 발송 작업으로 분리합니다.

### 카카오 채널 메시지 초안

```text
(광고) [NOPS] 콜키지 프리 이용 감사

콜키지 프리 혜택을 이용해 주신 멤버십 고객님께
다음 방문을 위한 혜택을 다시 준비했습니다.

멤버십 쿠폰 확인하기
https://membership.nops.kr/mypage
```

카카오 채널 메시지는 개인 쿠폰 코드를 직접 넣지 않고, 멤버십 페이지에서 본인 확인 후 쿠폰을 확인하도록 연결합니다. 채널 친구 메시지와 CRM 회원 메시지는 동일 고객에게 같은 캠페인을 반복 전송하지 않도록 발송 이력으로 분리 관리합니다.

## 4. 발송 전 운영 확인표

| 확인 항목 | 통과 기준 |
|---|---|
| 쿠폰 대상 | 사용 완료 후 정확히 30일, 활성 회원, 당일 재발급 미완료 |
| 쿠폰 생성 | 재발급 쿠폰 생성 성공 및 회원별 1장 여부 확인 |
| SMS 대상 | SMS 마케팅 동의·수신거부 제외·휴대전화 보유 |
| 발송 시간 | 08:00~20:50 KST |
| 발송 문구 | 쿠폰 확인 링크·문의처·무료수신거부 포함 |
| 중복 관리 | 동일 캠페인·동일 채널 기준 1회 발송 이력 확인 |

> 현재 콜키지 재발급 알림의 실제 자동 발송은 활성화되지 않았습니다. 따라서 위 문구는 발송 승인·채널 요건·발송 이력 기능을 갖춘 뒤 사용해야 하며, 오늘은 대상이 0명이라 발송할 메시지가 없습니다.
