# 가입 환영 알림톡 장애 분석 및 복구 기록

## 결론

가입 환영 알림톡 대량 실패의 직접 원인은 `SOLAPI_TEMPLATE_WELCOME`이 SOLAPI 계정에서 더 이상 존재하지 않는 템플릿 ID를 가리킨 것이었다. SOLAPI API 인증키, 카카오 프로필, 승인 발신번호는 접근 가능했고, 승인된 **NOPS 멤버십 가입 완료** 알림톡 템플릿은 동일 카카오 프로필에서 확인됐다.

## 영향과 근거

최근 30일 기준 `welcome` 발송 로그에서 실패가 995건, 성공이 490건이었다. 실패는 2026-08-25 KST 이후 반복됐으며, 기존 코드는 SOLAPI 오류를 `String(err)`로만 저장해 `failedMessageList`의 수신 거부·템플릿·발신번호 등 개별 실패 원인이 보존되지 않았다.

읽기 전용 SOLAPI 점검 결과는 다음과 같다.

| 점검 항목 | 복구 후 상태 |
|---|---|
| API 인증 및 잔액 조회 | 정상 |
| 가입 환영 템플릿 설정 | 승인 완료 템플릿으로 정정 |
| 템플릿 승인 상태 | `APPROVED` |
| 템플릿 카카오 프로필 일치 | 일치 |
| 승인 발신번호 | `02-597-4030` |
| 템플릿 본문 존재 | 확인 |

## 적용 조치

`sendWelcomeAlimtalk()`은 빈 템플릿 ID를 즉시 차단하고, SOLAPI `MessageNotReceivedError`의 `statusCode`, `statusMessage`, `totalCount`, `failedMessageList`를 구조화해 기록한다. 진단 로그에는 수신·발신 번호를 넣지 않아 상세 사유를 보존하면서 추가 개인정보 노출을 줄인다.

SOLAPI 발신번호는 콘솔 승인 번호 `02-597-4030`으로 정정했다. 가입 환영 템플릿도 승인된 **NOPS 멤버십 가입 완료** 템플릿으로 바꿨고, 실제 API 조회로 템플릿 존재·승인·프로필 일치를 검증했다.

추가 분석 결과, 실제 회원 가입 절차는 환영 이메일과 함께 `sendWelcomeAlimtalk()`을 비동기로 호출한다. 반면 별도의 `/api/admin/test-alimtalk` 경로는 이전에 인증 검사가 없어 특정 회원명으로 테스트 전송을 요청할 수 있었다. 이 경로를 관리자 권한 계정만 호출할 수 있도록 제한해, 외부 요청이나 일반 계정의 반복 테스트가 발송 로그·잔액·고객 수신에 영향을 주지 못하게 했다.

## 검증

전체 TypeScript 검사와 Vitest 17개 파일·54개 테스트를 통과했다. 여기에는 SOLAPI 실계정 잔액 조회, 승인 발신번호 확인, 승인된 가입 환영 템플릿 조회, 상세 실패 사유의 비식별 저장 테스트가 포함된다.

후속 보정으로 MMS 이름 직접 삽입과 관리자 테스트 전송 권한을 포함한 전체 TypeScript 검사 및 Vitest 19개 파일·58개 테스트도 통과했다.

## 운영 제한

기존 실패 991건은 자동 재발송하지 않는다. 실패 당시의 회원 상태, 현재 동의 상태, 이미 수신한 이메일 또는 알림톡, 중복 발송 가능성을 개별적으로 확인한 뒤 별도 승인을 받아야 한다. 다음 신규 가입 1건에서만 정상 발송 로그를 확인해 복구 효과를 검증한다.
