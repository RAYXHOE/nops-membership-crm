# NOPS 고객군별 메시지·쿠폰 운영 체계

작성일: 2026-08-29

## 운영 원칙

세 고객군을 하나의 발송 목록으로 합치면 쿠폰 중복·수신 동의 범위 혼선·불필요한 재발송이 생긴다. 카카오톡 채널은 **대규모 유입**, 수기 가입 고객은 **멤버십 가입 완료**, 기존 멤버십 쿠폰 사용 고객은 **사용 이력 기반의 재방문 관리**로 목적을 나눈다.

카카오 채널 친구와 CRM 회원을 직접 동일인으로 간주하지 않는다. 고객은 이벤트 링크에서 OTP로 본인 인증한 뒤에만 CRM 회원 상태·쿠폰 사용 이력·캠페인 혜택 자격을 확인한다.

## 고객군별 메시지와 혜택 기준

| 고객군 | 식별 기준 | 메시지 채널·목적 | 쿠폰 처리 | 제외 기준 |
|---|---|---|---|---|
| 카카오톡 NOPS 채널 친구 | 약 7,700명, CRM 직접 매칭 없음 | 브랜드 메시지로 이벤트 인지도·가입/이벤트 링크 유입 | 링크 인증 후에만 대상별 쿠폰 발급 | 이미 해당 캠페인 쿠폰을 받은 회원 |
| 수기 가입 고객 | 동의서·연락처 보유, CRM 가입 미완료 | SMS로 멤버십 가입 링크 안내 | 가입 완료 후 기본 콜키지 쿠폰, 이메일·SMS 마케팅 동의 시 가입 10% 쿠폰 | SMS 동의 미확인, 중복 CRM 회원, 미성년 법정대리인 동의 미확인 |
| 콜키지 프리 쿠폰 사용 회원 | `corkage_free` 쿠폰이 사용 완료 | 사용 감사·재발급 가능 사실 안내 | 사용 완료 후 **30일**에 콜키지 프리 쿠폰 1장 재발급, 발급일+365일 유효 | 비활성/탈퇴, 당일 재발급 완료, 수신 동의·발송 차단 |
| 가입 10% 할인 쿠폰 사용 회원 | 가입 기념 `discount_percent` 쿠폰이 사용 완료 | 감사 이벤트·새 캠페인 링크 안내 | 가입 10%는 **재발급하지 않음**. 감사 이벤트는 별도 캠페인 쿠폰·별도 발급 키로 1회만 제공 | 기존 캠페인 쿠폰 수령/사용, 수신 동의 없음, 수신 거부 |

## 채널별 메시지 목적

### 카카오톡 채널 브랜드 메시지

카카오톡 채널 친구에게는 개인 쿠폰 코드가 아니라 이벤트 페이지 링크를 보낸다. 메시지의 목적은 신규 가입 또는 기존 회원의 이벤트 인증 유입이다. 링크에 `utm_source=kakao`와 `campaignId`를 포함하고, 고객이 인증하면 CRM이 신규·기존 회원 및 쿠폰 사용 이력에 맞는 화면을 보여준다.

| 유입 뒤 상태 | 이벤트 페이지 동작 |
|---|---|
| 미가입 고객 | 멤버십 가입으로 이동. 개인정보 필수 동의와 이메일·SMS 마케팅 동의, 카카오톡 수신 동의를 각각 선택 |
| 가입 완료 회원, 캠페인 미수령 | 캠페인 자격을 확인하고 조건 충족 시 이벤트 쿠폰 1회 발급 |
| 기존 10% 가입 쿠폰 사용 회원 | 기존 10% 재발급 대신 별도 감사 이벤트 쿠폰 자격 확인 |
| 콜키지 쿠폰 사용 후 30일 경과 회원 | 기존 콜키지 재발급 쿠폰 보유 여부를 확인하고 쿠폰함으로 연결 |
| 이미 캠페인 수령 회원 | 쿠폰 중복 발급 없이 쿠폰함으로 연결 |

### 수기 가입 고객 SMS

수기 가입 고객은 고객이 직접 이메일·연락처·생년월일을 확인하고 동의 항목을 선택하게 하는 가입 링크 SMS가 목적이다. CRM에 일괄 강제 등록하는 방식보다 오기입·동의 범위 오류를 줄일 수 있다. 이메일 누락 고객에게도 전화번호만 있으면 링크를 안내할 수 있다.

SMS를 광고성 행사 안내로 사용하면 SMS 마케팅 동의·수신 거부·발송 시간·광고성 표기가 필요하다. 가입 완료만을 위한 개별 안내로 운영하려 해도 수기 동의서에서 해당 연락 수단과 안내 목적을 확인한 고객으로만 제한한다.

> `[NOPS] 멤버십 가입 안내\n고객님의 NOPS 멤버십 등록을 위해 아래 링크에서 정보를 확인해 주세요. 가입 후 제공 혜택은 화면에서 확인할 수 있습니다.\n[가입 링크]\n문의: [고객센터]`

이 문구에 할인·쿠폰·행사 유도 표현을 추가하면 광고성 문자로 보고 `(광고)`, 문의처, `무료수신거부 080-500-4233`을 포함한다.

### 기존 멤버십 쿠폰 사용 회원 SMS

기존 회원에게는 CRM이 보유한 개인 쿠폰 상태를 기준으로 SMS를 쓴다. 같은 쿠폰을 사용했다는 사실만으로 동일 혜택을 다시 발급하면 안 된다. 특히 가입 10% 쿠폰은 회원당 1회 정책을 유지한다.

| 사용 이력 | 가능한 안내 | 발급 기준 |
|---|---|---|
| 콜키지 프리 쿠폰 사용 | 사용 감사 및 재발급 쿠폰 확인 안내 | D+30 재발급 성공 후, SMS 동의·발송 요건 충족 시 1회 안내 |
| 가입 10% 쿠폰 사용 | 별도 9월 감사 이벤트 참여 안내 | 별도 쿠폰 유형·`campaignId`·`grantKey`로 1회 발급 |
| 행사 쿠폰 사용 | 캠페인 종료·다음 혜택 안내 | 동일 캠페인 재발급 금지, 새 캠페인 조건을 별도 정의 |

## 권장 발송 순서

| 시점 | 대상 | 행동 | 중복 방지 |
|---|---|---|---|
| D0 10:00 KST | 카카오 채널 친구 | 이벤트 링크 브랜드 메시지 1회 | `campaignId`와 카카오 발송 이력 기록 |
| D0~D3 | 이벤트 링크 유입자 | OTP 인증·가입 또는 쿠폰 자격 확인 | 회원별 `campaignId` 쿠폰은 1회만 발급 |
| D3~D4 | 미가입 수기 고객 | 가입 링크 SMS 1회 | 전화번호·SMS 동의·CRM 미가입 확인 |
| D3~D4 | 미전환 CRM 마케팅 동의 회원 | 이벤트 링크 SMS 1회 | 카카오 링크 인증/캠페인 쿠폰 수령자는 제외 |
| 쿠폰 발급 직후 | 쿠폰 수령 CRM 회원 | 개인 쿠폰 코드·만료일 SMS | 동일 `couponId` 안내 이력 1회만 허용 |
| 콜키지 사용 D+30 | 재발급 조건 충족 회원 | 재발급 쿠폰 안내 | 당일 재발급·발송 이력 확인 |

## 공통 제외와 기록 기준

모든 발송 전에 아래 조건을 검사한다.

1. `status = active`인지 확인한다.
2. SMS는 `marketingConsent = true`이고 SOLAPI 수신거부·내부 차단 목록에 없는지 확인한다.
3. 카카오 채널은 채널 친구 대상 브랜드 메시지 설정과 템플릿 요건을 만족하는지 확인한다.
4. 동일 `campaignId`와 채널로 이미 발송·수령·사용한 기록이 있는지 확인한다.
5. 광고성 발송은 08:00~20:50 KST에만 예약하고, SMS에 `(광고)`, 발송 주체, 문의처, 수신거부 번호를 넣는다.
6. 발송 요청 ID, 대상 전화번호 해시 또는 회원 ID, 채널, 시각, 결과, 실패 상세 사유를 남긴다.

## 정책상 금지 항목

가입 10% 할인 쿠폰을 감사 이벤트라는 명목으로 다시 발급하지 않는다. 반드시 별도 캠페인 쿠폰을 사용하고, 기존 가입 혜택과 다른 발급 키를 적용한다. 카카오 채널 메시지에는 개인 정보나 개인 쿠폰 코드를 노출하지 않으며, 이벤트 페이지 본인 인증 후에만 제공한다.
