# 9월 콤보 전 메뉴 10% 쿠폰 MMS 테스트 발송 준비표

## 1. 현재 확인된 상태

2026-09-10 기준, `sep_combo_2026_v1` 이벤트 쿠폰은 **2,744건**이 발급되어 있으며 모두 활성 상태입니다. 회원별 중복은 없고, 쿠폰명은 **9월 콤보 전 메뉴 10% 할인 쿠폰**, 만료 시각은 **2026-10-11 23:59:59 KST**로 일치합니다.

따라서 MMS에는 ‘쿠폰이 발급되었습니다’라는 문구를 사용할 수 있습니다. 다만 테스트 수신자는 실제로 이 쿠폰을 가진 회원 계정으로 로그인·본인 인증까지 할 수 있어야 쿠폰 확인 링크를 끝까지 검증할 수 있습니다.

## 2. 테스트 전에 준비할 항목

| 항목 | 준비 기준 | 테스트에서 확인할 내용 |
|---|---|---|
| 테스트 수신자 | 내부 운영자 1~3명, 가능하면 iPhone·Android 각각 1대 이상 | 이름 치환, 이미지 표시, 링크 인식 차이 |
| 쿠폰 보유 여부 | 테스트 수신자마다 `sep_combo_2026_v1` 쿠폰이 실제 존재 | 마이페이지에서 10% 쿠폰과 2026-10-11 만료일 확인 |
| MMS 이미지 | JPG, 200KB 이하, 가로 1,500px 이하·세로 1,440px 이하 | 메시지 앱에서 잘림·문구 가독성·기간 일치 확인 |
| 본문 | 최종 확정 문구와 동일 | `(광고)`, 메뉴 범위, 문의처, 080 표기 확인 |
| 발신번호 | SOLAPI에 등록·인증된 NOPS 번호 | 콘솔에서 발신번호 선택 가능 여부 |
| 수신거부 | 080을 본문 수동 삽입 또는 콘솔 자동 삽입 중 하나로만 적용 | 미리보기와 단말기에서 `080-500-4233`이 한 번만 표시되는지 확인 |
| 링크 | 멤버십 마이페이지·카카오 메뉴 링크 | 로그인/OTP 후 쿠폰 확인, 메뉴 링크의 실제 NOPS 채널 이동 |

## 3. 콘솔 입력값

테스트 수신자 업로드 파일은 XLSX 형식으로 만들고 첫 행을 `이름`, `수신번호`로 둡니다. 전화번호 열은 텍스트 형식으로 저장해 앞자리 `0`이 사라지지 않도록 합니다. 테스트 단계에서는 전체 발송 대상 파일을 업로드하지 않습니다.

```text
(광고)[NOPS] 쿠폰 발급!

#{이름}님, 9월 콤보 전 메뉴 10% 할인 쿠폰이 발급되었습니다.
쿠폰 확인: https://membership.nops.kr/mypage

사용 기간: 2026.10.11까지
적용 메뉴: 콤보 전 메뉴(런치 / 디너 / 베네핏 신메뉴)
메뉴 확인: https://pf.kakao.com/_AAxjEn/114522532

문의: 02-597-4030
무료수신거부: 080-500-4233
```

SOLAPI 콘솔에서 **메시지 → 메시지 보내기 → 문자 메시지**로 이동해 발신번호, 테스트 수신자 1~3명, 위 본문, JPG 이미지를 넣습니다. 이미지가 첨부되면 메시지 유형이 MMS로 표시돼야 합니다.[1] `광고 메시지` 설정에서 080을 자동 추가하는 경우에는 본문의 `무료수신거부: 080-500-4233` 행을 삭제하고, 한 경로만 사용합니다.

## 4. 테스트 통과 기준

| 검수 항목 | 통과 기준 |
|---|---|
| 메시지 유형 | SOLAPI 미리보기에 MMS로 표시 |
| 개인화 | `#{이름}`이 수신자 이름으로 치환되고 변수 원문이 남지 않음 |
| 이미지 | 음식 이미지·혜택·기간이 잘리지 않고 읽힘 |
| 광고 고지 | `(광고)`, 문의처, 080 수신거부가 각각 한 번만 표시 |
| 쿠폰 링크 | 로그인 또는 OTP 후 테스트 수신자의 마이페이지에서 해당 쿠폰 확인 |
| 메뉴 링크 | NOPS 카카오 채널 메뉴 페이지로 이동 |
| 기간·조건 | 2026.10.11, 런치·디너·베네핏 신메뉴 포함, 타 할인 중복 불가와 실제 쿠폰 정책 일치 |
| 전송 결과 | SOLAPI 전송요청내역에서 테스트 건 접수 결과와 실패 사유 확인 |

## 5. 본발송을 막아야 하는 경우

다음 중 하나라도 발생하면 전체 발송을 예약하지 않습니다.

| 차단 조건 | 필요한 조치 |
|---|---|
| 080 번호가 두 번 보이거나 누락됨 | 본문 수동 삽입과 콘솔 자동 삽입 중 하나만 유지 |
| 테스트 수신자 마이페이지에 쿠폰이 없음 | 대상·쿠폰 발급 상태를 먼저 재검증 |
| 이미지가 잘리거나 본문과 기간·메뉴가 다름 | 이미지·본문을 수정하고 다시 테스트 |
| URL이 잘못된 채널 또는 로그인 오류로 이동 | 실제 URL·인증 흐름을 수정하고 재시험 |
| 발신번호 또는 광고 메시지 설정이 미확정 | SOLAPI 콘솔 설정 완료 전 발송 보류 |
| 발송 대상 파일에 수신거부·비동의·중복 발송 대상이 포함됨 | CRM·SOLAPI 차단 목록과 발송 이력을 다시 필터링 |

테스트가 통과한 뒤에도 본발송 파일은 `활성 회원 + SMS 마케팅 동의 + SOLAPI/내부 수신거부 제외 + 이번 캠페인 MMS 미발송` 조건으로 새로 생성합니다. 광고성 MMS는 **08:00~20:50 KST** 사이에만 예약합니다.[2]
