## 알림 내용과 안전장치

쿠폰 발급 후 이메일과 LMS 대기 기록을 별도로 만든다. 실제 발송 직전에 현재 회원 활성·마케팅 동의 및 최신 철회 이력, 연락처 변경, 기념일 날짜, 실제 쿠폰 사용 가능 상태를 재확인한다. LMS는 계정 잔액·당일 한도·수신거부 목록을 끝까지 확인한다. 같은 번호의 활성 회원이 복수이면 자동 문자에서 차단한다.

제목에 광고/NOPS/쿠폰 혜택을 표시하고 실제 회원 이름을 직접 삽입한다. `#{이름}` 같은 미해결 변수를 허용하지 않는다. 쿠폰 코드·실제 만료일·마이페이지 링크·문의 02-597-4030을 안내한다. 할인 쿠폰끼리는 중복 불가이며 콜키지 프리 쿠폰은 함께 사용 가능하다는 운영 기준을 명시한다.

LMS는 이미지 없는 장문 문자이며 무료수신거부 `080-500-4233`을 본문에 한 번 포함한다. 기준 LMS 요금은 45원(VAT 별도), 49.5원(VAT 포함)이며 채널 준비 검사에서 잔액 단위를 합산하거나 혼용하지 않는다. 자동 결제·자동 충전을 수행하지 않는다. 요금 정책 변경 시 실제 계정 요금 및 예산을 재검토해야 한다.

이메일 수신거부는 마이페이지와 `contact@nops.kr` 회신 경로를 제공한다. 운영자는 메일로 들어온 철회 요청도 CRM 동의에 반영해야 한다. 카카오 기념일 자동 발송은 활성화하지 않는다.

## 상태의 의미

| 상태 | 의미 |
|---|---|
| pending | 아직 전송을 시도하지 않은 대기 |
| sending | 전송 시도 시각 저장됨. 처리 중 또는 기록 미확정 |
| accepted | 제공사 접수. 실제 수신 완료가 아님 |
| delivered | 제공사에서 전달 완료 확인. 고객 열람 확인이 아님 |
| failed | 확인된 발송 실패 |
| unknown | 네트워크/결과/기록 불명. 자동 재발송 금지 |
| cancelled | 동의·연락처·날짜·쿠폰 상태 변경으로 전송 취소 |
| blocked | 잔액·한도·번호 중복·검증 실패 등으로 전송 차단 |

DB에 시도 시각을 먼저 저장한 뒤 한 번만 전송한다. 응답 불명·실패·처리 중·접수 대기를 자동 재전송하지 않는다. 잔액 등으로 차단된 알림의 해제 역시 운영 검토 대상이다. 전달 조회는 GET만 사용한다. 이메일 이력 조회 권한이 없거나 통신사 최종 응답이 없으면 접수 상태를 수신 완료로 바꾸지 않는다.
