# NOPS 멤버십 고객 본인 이메일·연락처 수정

기준: 2026년 11월 11일. 기능 구현·개발 환경 검증을 완료했으며, 운영 사이트 반영은 최신 체크포인트 게시 후 확인해야 합니다. 이번 작업에서 실제 회원 정보를 수정하거나 실제 인증 메일·문자를 발송하지 않았습니다.

## 고객 이용 방법

1. 마이페이지에서 가입 시 등록한 이메일 또는 휴대폰으로 본인인증합니다. 이메일이 잘못 등록됐다면 정상 등록된 휴대폰의 문자 인증으로 로그인할 수 있습니다. 휴대폰이 잘못 등록됐다면 정상 등록된 이메일로 로그인합니다.
2. 쿠폰 화면의 **회원정보 수정 → 수정**을 누릅니다.
3. 바꿀 이메일·연락처·생년월일을 입력합니다. 새 이메일은 해당 주소로 받은 인증코드를, 새 연락처는 해당 번호로 받은 문자 인증코드를 확인합니다. 둘 다 바꾸면 두 인증을 모두 완료해야 합니다.
4. **변경 저장**을 누릅니다. 인증만 완료한 상태에서는 회원정보가 변경되지 않습니다. 여러 항목을 한 번의 저장으로 반영할 수 있습니다.

## 수정 제한

이메일·연락처·생년월일 변경은 **합산 월 1회**입니다. 매월 1일 00:00 한국시간에 다시 수정할 수 있습니다. 여러 항목을 한꺼번에 저장해도 1회이며, 변경 내용이 없거나 저장에 실패하면 횟수를 소진하지 않습니다. 이번 달에 이미 수정했다면 다음 수정 가능일을 표시합니다. 긴급 정정은 고객 문의로 처리합니다.

기존 쿠폰·포인트·마케팅 수신동의는 변경하지 않습니다. 결혼기념일 정책은 이번 변경 범위에 포함하지 않았습니다. 이메일 변경은 신규 회원 가입이나 쿠폰 재발급으로 처리하지 않습니다.

## 본인인증과 예외

새 이메일·새 전화번호의 소유 인증 증거는 현재 로그인 세션, 회원, 변경 대상에 결합하며 저장 트랜잭션에서 한 번만 소비합니다. 이메일·전화번호와 월 수정 시각을 함께 저장하고, 어느 조건이든 실패하면 전부 롤백합니다. 변경 후에는 새 연락처에 결합한 토큰을 반환하므로 변경 전 토큰으로 계속 수정할 수 없습니다.

신규 문자 로그인 및 연락처 변경 인증은 10분 유효, 잘못된 코드 5회 제한, 재요청 60초 간격 및 대상/회원별 시간당 5회 제한을 사용합니다. 신규 인증 테이블에는 평문 인증번호가 아니라 목적·챌린지 ID에 결합한 HMAC을 저장합니다. 실패·불확실한 발송은 자동 재전송하지 않습니다. 문자 인증은 서비스 이용용 비광고 메시지이며 마케팅 동의값을 변경하지 않습니다.

이메일과 휴대폰이 **둘 다 잘못 등록**됐거나 동일 번호의 기존 회원이 여러 명이면 자동 복구하지 않습니다. 고객 문의 또는 contact@nops.kr를 통한 관리자 확인이 필요합니다. 다른 회원이 이미 사용하는 이메일·연락처로 변경하는 요청도 차단합니다.

## 검증과 배포

TypeScript 검사, Vitest **24개 파일·168개 테스트**, 운영 빌드를 통과했습니다. 실제 네트워크의 고객 API 호출을 mock으로 차단한 UI 검증에서 휴대폰 로그인 복구, 새 이메일·번호 인증, 단일 저장, 월 제한, 토큰 갱신, URL 회원번호만으로 수정 불가를 확인했습니다. 360×800, 390×844, 768×1024, 1440×900 화면에서 기능을 확인했고 추가 3개 화면의 가로 넘침이 없음을 검증했습니다.

새 인증 테이블과 조회 인덱스, 전화번호 변경 인증 목적을 운영 DB에 적용했습니다. 기존 회원·쿠폰 데이터는 일괄 보정하지 않았습니다. 신규 실제 인증 레코드는 확인 시점 0건입니다.

이번 환경의 공개 사이트 조회는 HTTP 403으로 제한되어 새 버전의 운영 반영 여부를 확정하지 못했습니다. 최신 체크포인트를 **게시(Publish)**한 뒤 실제 고객이 본인 요청한 인증으로 운영 동작을 확인해야 합니다. 승인 없는 테스트 고객 생성·실제 테스트 문자 추가 발송은 하지 않습니다.
