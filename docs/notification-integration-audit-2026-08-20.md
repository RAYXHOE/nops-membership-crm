# SOLAPI·Resend 발송 연동 점검

점검일: 2026-08-20 KST  
대상: NOPS 멤버십 CRM의 고객 알림톡 및 이메일 발송 경로

## 결론

SOLAPI 인증과 기본 알림톡 발송은 정상이다. 가입 환영, 쿠폰 만료 D-7, 적립금 적립은 현재 실제 성공 로그가 존재한다. 그러나 결혼기념일과 콜키지 재발급은 환경변수가 가리키는 템플릿이 SOLAPI 계정에 존재하지 않아 최근 발송이 실패했다.

또한 생일 쿠폰 발급과 적립금 만료 D-30 알림에 만료 D-7 또는 적립금 적립용 템플릿을 재사용하고 있다. 발송 자체가 성공하더라도 메시지의 발송 사유·시점이 실제 이벤트와 다르다.

Resend 키는 발송 전용 제한 키다. 도메인 목록 조회는 권한 부족으로 실패하지만, 배포 로그에서 최근 환영 이메일 3건이 Resend에 정상 접수된 것을 확인했다. 현재 애플리케이션에는 이메일 발송 결과를 DB에 영속 저장하는 구조가 없어, 수신함 도착·반송·스팸 판정까지의 장기 추적은 불가능하다.

## 환경변수와 연결 상태

| 연동 | 필수 키 | 설정 상태 | 연결 상태 |
|---|---|---:|---|
| SOLAPI | API Key, API Secret, PFID, 발신번호, 환영·만료·기념일·콜키지·적립금 템플릿 ID | 모두 설정 | 잔액 조회 성공 |
| Resend | API Key, 발신자 주소 | 모두 설정 | 발송 전용 제한 키. 도메인 조회는 `restricted_api_key`로 거부됨 |

## 승인된 SOLAPI 템플릿

| 용도 | 템플릿명 | 상태 | 코드 변수와의 일치 |
|---|---|---|---|
| 가입 환영 | `Welcome_Family` | 승인 | 이름 변수만 승인됨. 코드가 넘기는 쿠폰 목록·링크 변수는 본문에 없음 |
| 쿠폰 만료 D-7 | `쿠폰만료 알림` | 승인 | 이름·쿠폰명·만료일이 일치 |
| 적립금 적립 | `놉스 포인트_알림` | 승인 | 이름·적립금액·잔액·만료일이 일치 |
| 결혼기념일 | 설정 ID 조회 실패 | 미존재 | 현재 발송 실패 |
| 콜키지 재발급 | 설정 ID 조회 실패 | 미존재 | 현재 발송 실패 |

## 메시지 내용과 실제 이벤트 불일치

| 이벤트 | 현재 발송 방식 | 문제 |
|---|---|---|
| 가입 환영 | 환영 템플릿 | 본문은 ‘쿠폰 유효기간: 가입일로부터 30일’이라고 고지. 실제 가입 10%·콜키지 쿠폰은 각각 365일 |
| 생일 쿠폰 발급 | 쿠폰 만료 D-7 템플릿 재사용 | 발급 시점에 ‘7일 후 만료’라고 안내. 실제 생일 쿠폰 유효기간은 60일 |
| 결혼기념일 쿠폰 발급 | 미존재 템플릿 ID 사용 | 2026-08-01 기준 4건의 최근 발송 실패 |
| 콜키지 재발급 | 미존재 템플릿 ID 사용 | 2026-08-17까지 최근 21건이 수신 거부로 실패 |
| 적립금 만료 D-30 | 적립금 적립 템플릿 재사용 | 만료 예정 알림이 ‘결제금액의 3%가 적립’된 메시지로 발송될 위험 |

## 권고 조치

1. SOLAPI에 결혼기념일, 콜키지 재발급, 생일 쿠폰 발급, 적립금 만료 D-30용 템플릿을 각각 승인받고 환경변수 ID를 갱신한다.
2. 환영 템플릿의 ‘30일’을 실제 365일 정책에 맞추거나, 쿠폰별 유효기간을 고정 문구로 쓰지 않도록 변경한다.
3. `kakao.test.ts`에서 DB 로깅을 모킹해 테스트 실패 기록이 운영 `alimtalk_logs`에 남지 않게 한다.
4. Resend 응답 ID·상태·오류를 DB에 저장해 운영 대시보드에서 이메일 발송 결과를 추적한다.
