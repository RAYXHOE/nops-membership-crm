# 2026년 8월 Manus 데이터 분리: NOPS 멤버십 CRM 영향 및 운영 대응

작성일: 2026-08-18 KST  
대상 서비스: `membership.nops.kr` / NOPS 멤버십 CRM

## 결론

현재 계정 안내문은 영향 대상임을 명시한다. 따라서 NOPS 멤버십 CRM은 **2026년 8월 23일 09:00 KST부터 8월 25일 08:59 KST까지** 일시적으로 운영할 수 없다고 전제해야 한다. 이 기간에는 QR 주소 자체가 바뀌지 않지만, `membership.nops.kr`은 가입 페이지 대신 표준 점검 화면을 응답한다.

사이트와 데이터는 8월 25일 09:00 KST에 자동으로 돌아오지 않는다. 저장해 둔 최신 Task Data 백업을 복구해야만 다시 서비스된다. 계정 데이터 내보내기가 제공된 안내 상태이므로, 복구 시에는 계정 백업을 먼저 복원한 다음 Task Data 백업을 복원하는 순서를 준비해야 한다.

## 이미 확보한 백업과 부족한 범위

| 항목 | 화면상 확인된 상태 | 판단 |
|---|---|---|
| 계정 데이터 백업 | 2026-08-12 17:56 SGT 내보내기 완료 | 복구 자격 확인용으로 보관 필요 |
| 작업 데이터 백업 | 2026-08-18 07:15 SGT 내보내기 완료 | 해당 시점의 코드·DB·시크릿·설정 복구 가능 |
| 8월 18일 07:15 SGT 이후 가입·쿠폰·적립·수정 | 현재 백업에는 포함되지 않음 | 최종 Task Data 백업에 반드시 포함해야 함 |
| Cloudflare R2 일일 DB 백업 | 별도 운영 중 | DB 복구 보조 수단이며 웹사이트 전체 복구 대체 수단은 아님 |

Task Data 백업은 생성 시점의 고정 스냅샷이다. 따라서 8월 18일 07:15 SGT 이후 발생하는 신규 가입, 쿠폰 발급·사용, 포인트 적립·사용, 관리자 수정, 템플릿 변경 및 스케줄러 변경은 이후에 다시 내보내지 않으면 복구본에 들어가지 않는다.

## 서비스별 영향

| 구성 요소 | 8/23 09:00 KST~8/25 08:59 KST 영향 | 복구 후 조치 |
|---|---|---|
| 고객 가입·마이페이지 | QR 스캔 후 가입·로그인·쿠폰 조회 불가 | 최신 Task Data 복원 후 가입/조회 정상화 확인 |
| 쿠폰 발급·사용 | 자동 발급, QR 사용 처리, 수동 발급 모두 불가 | 중단 기간 수기 처리분을 후입력 |
| 적립금 | 적립·사용·만료 처리 불가 | 중단 기간 결제 내역 기준으로 적립금 후처리 |
| 관리자 대시보드 | 회원·쿠폰·지점·분석 화면 접근 불가 | 관리자 권한 및 통계 데이터 확인 |
| TiDB 데이터베이스 | 웹앱과 직접 연결 모두 불가 | Task Data 백업 복원으로 복구 |
| Heartbeat 자동화 | 생일·기념일 쿠폰, 만료 알림, 누락 점검, DB 백업 미실행 | 복구 후 스케줄러 상태와 누락 작업 점검 |
| 카카오 알림톡·이메일 | 웹앱에서 기동되는 자동 발송 중단 | 복구 후 발송 키·템플릿 연결 확인 |
| 도메인·QR 코드 | QR URL은 변경할 필요 없음. 점검 화면이 표시됨 | `membership.nops.kr` 재연결 상태 확인 |

## 필수 실행 순서

1. 현재 보관된 `account-data-...manusaccount` 파일과 `tasks-data-...manustask` 파일을 외부 저장소에서 실제로 열람 가능한지 확인한다. 파일명 변경, 압축 해제, 분할 파일의 교차 조합은 하지 않는다.
2. 8월 22일 영업 종료 후 최신 **Task Data 전체 백업**을 실행한다. 모든 작업/전체 기간 내보내기를 우선한다.
3. 8월 23일 08:30 KST 전후에 마지막 **Task Data 전체 백업**을 다시 실행한다. 이 백업이 중단 직전 신규 가입·쿠폰·포인트 변경을 가장 많이 포함한다. 마감은 08:59 KST다.
4. 매장에는 중단 시간 동안 QR 가입, 쿠폰 사용, 포인트 적립·사용이 처리되지 않는다는 운영 공지를 전달한다. 중단 기간 거래는 고객 식별 최소 정보, 결제 시각, 매장, 결제금액, 적용 할인, 쿠폰 코드만 보호된 수기대장에 기록해 복구 후 후입력한다.
5. 8월 25일 09:00 KST 이후 계정 백업을 먼저 복원하고, 검증한 최신 Task Data 패키지를 한 번에 복원한다. 복구는 한 번만 실행할 수 있으므로 이전·최신 백업 파일을 모두 준비한 상태에서 진행한다.
6. 복구 뒤 `membership.nops.kr/register`, 관리자 로그인, 신규 가입 테스트, 쿠폰 조회, 포인트 조회, Heartbeat 스케줄러, Solapi/Resend 시크릿 및 커스텀 도메인을 순서대로 점검한다.

## 유의사항

QR 코드와 도메인을 교체하거나, 약 이틀의 중단만을 이유로 DNS를 다른 호스팅으로 이전하는 것은 권장하지 않는다. `membership.nops.kr` 바인딩은 복구 후 자동 재연결이 예상되며, 연결이 실패할 경우에만 WebDev 설정의 도메인 메뉴에서 재연결을 확인한다.

R2의 일일 DB 백업은 중요한 이중 안전장치다. 그러나 이 백업만으로는 Manus에 저장된 웹사이트 코드, 환경변수, 배포 설정, 도메인 연결, 로그인 및 자동화 구성을 일괄 복구하지 못한다. 따라서 **Task Data 백업이 주 복구본이며, R2 백업은 DB 데이터 검증 및 보조 복구본**으로 취급한다.
