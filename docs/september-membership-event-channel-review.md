# 9월 멤버십 이벤트 쿠폰: 카카오 채널 메시지 검토

작성일: 2026-09-02  
검토 범위: 이미지·링크·카카오톡 채널 친구 연계·첨부 시안의 메시지 및 쿠폰 구조

## 결론

첨부 시안처럼 **이미지형 카카오 브랜드 메시지**, **이벤트 링크 버튼**, **쿠폰 강조 영역**은 모두 사용할 수 있다. 다만 NOPS 채널 친구 약 7,700명 전체를 SOLAPI API에서 자동으로 불러와 발송하는 것은 현재 조건에서 불가하다. SOLAPI의 채널 친구 전체 대상 기능은 채널 친구 5만 명 이상을 전제로 하며, 현재 NOPS는 이 기준에 미달한다.[1]

따라서 이번 이벤트는 다음 둘 중 하나로 운영해야 한다.

| 경로 | 가능한 대상 | 핵심 제약 |
|---|---|---|
| SOLAPI 브랜드 메시지 `I` 타게팅 | CRM에 전화번호가 있는 회원 중 실제 채널 친구인 고객 | 메시지마다 수신번호가 필요하며, 비친구에게는 발송되지 않음 |
| 카카오 채널 관리자센터의 별도 채널 메시지 기능 | 채널 관리자센터에서 제공하는 실제 친구 대상 옵션을 확인한 경우 | SOLAPI CRM·쿠폰 발급 이력과 자동 연결되지 않음 |
| CRM SMS/LMS | SMS 마케팅 동의가 있는 활성 회원 | 카카오 친구 여부와 무관하지만 광고성 SMS 요건 및 080 표기가 필요 |

현재 CRM에는 카카오 채널 친구 여부가 저장되어 있지 않다. 따라서 **채널 친구 7,700명에게 먼저 링크를 안내하고, 이벤트 페이지에서 OTP 인증 후에만 멤버십 이벤트 쿠폰을 발급**하는 방식이 개인정보·쿠폰 중복 관점에서 가장 안전하다.

## 1. 이미지 첨부 가능 여부

가능하다. SOLAPI 브랜드 메시지의 이미지형(`IMAGE`)은 이미지 ID, 본문, 선택 버튼을 사용한다. JPG 또는 PNG, 최대 5MB이며 권장 크기는 800×400이다. 이미지 비율은 가로:세로 2:1 이상 3:4 이하이고, 본문은 400자·줄바꿈 29회 이내다.[2]

첨부한 파일은 **메시지 시안이 포함된 슬라이드 이미지**이지 발송용 크리에이티브 원본이 아니다. 발송에는 음식 사진과 이벤트 핵심 문구만 남긴 별도 JPG/PNG를 제작해야 한다. 슬라이드의 ‘네이버 마케팅 메시지 노출 예시’, 화살표, 설명문은 발송 이미지에 넣지 않는다.

권장 발송 이미지 구성은 아래와 같다.

| 이미지 영역 | 권장 내용 |
|---|---|
| 상단 | `NOPS 9월 멤버십 감사 이벤트` |
| 중앙 | 실제 제공 메뉴 사진 1장 또는 콤보 메뉴 사진 |
| 하단 | `콤보 메뉴 10% 할인 쿠폰`과 행사 종료일 |
| 제외 | 실제와 다른 메뉴·가격, 모호한 ‘전 메뉴’ 표현, 쿠폰 코드·개인정보 |

## 2. 링크 삽입 가능 여부

가능하다. 이미지 클릭 링크(`imageLink`)와 웹 링크 버튼(`WL`)을 함께 넣을 수 있다. 이미지형은 최대 5개 버튼을 둘 수 있으며 쿠폰 강조 기능을 쓰면 최대 4개다.[2]

그러나 현재 CRM에는 `/event/sep-combo-2026` 같은 **이벤트 페이지와 자동 쿠폰 수령 경로가 구현돼 있지 않다**. 등록된 공개 경로는 가입(`/register`)과 쿠폰 확인(`/mypage`)뿐이다. 따라서 시안의 “10% 할인 쿠폰 받기” 버튼에 임시 URL을 넣어 발송하면 고객이 쿠폰을 받을 수 없다.

권장 링크 구조는 아래와 같다. 이 경로는 구현 후에만 발송한다.

```text
https://membership.nops.kr/event/sep-combo-2026?utm_source=kakao&utm_medium=brand_message&utm_campaign=sep_combo_2026
```

이벤트 페이지는 전화번호 또는 이메일 OTP 인증을 거친 뒤 회원 상태를 확인하고, 자격이 있는 고객에게만 1회 발급해야 한다.

## 3. 카카오톡 채널 친구 연계 가능 여부

**채널 친구인지 판별해 발송하는 것은 가능하지만, CRM이 7,700명 친구 목록을 자동으로 갖고 있지는 않다.** SOLAPI 브랜드 메시지는 `I` 타게팅으로 채널 친구에게 발송할 수 있다. API 기준으로 수신번호·채널 프로필 ID·타게팅 값이 필요하다.[3]

`M`(마케팅 수신 동의자) 또는 `N`(마케팅 수신 동의자 중 채널 친구 제외)은 카카오 인허가 비즈니스 채널만 사용할 수 있다. NOPS 채널 친구 수는 약 7,700명으로 SOLAPI가 안내한 확장 발송 신청 기준인 5만 명에 미달한다.[1] 따라서 현재는 **CRM의 이메일·SMS 마케팅 동의자를 카카오 브랜드 메시지 대상으로 확장하면 안 된다.**

| 목적 | 권장 방식 | 발급 시점 |
|---|---|---|
| 채널 친구 7,700명에게 행사 알림 | 채널 친구 대상 브랜드 메시지 또는 채널 관리자센터 메시지 | 링크 클릭 전에는 쿠폰 미발급 |
| 기존 멤버십 회원 약 2,600명에게 개인 쿠폰 | SMS 동의 활성 회원에게 LMS/SMS 또는 채널 친구 검증 통과 회원에게 BMS | OTP 인증 후 회원별 1회 발급 |
| 신규 채널 친구를 멤버십 회원으로 전환 | 이벤트 링크 → 가입 → 동의 선택 | 가입 완료 후 정책상 혜택 발급 |

## 4. 첨부 시안의 문제점과 수정 제안

### 반드시 수정할 부분

| 시안 요소 | 문제 | 수정안 |
|---|---|---|
| `베네핏 스테이크 콤보 전 메뉴 10% 할인`과 `한 달간 콤보 전 메뉴 10% 할인` | 적용 메뉴 범위가 서로 다름 | `베네핏 스테이크 콤보 전 메뉴` 또는 `전 콤보 메뉴` 중 하나만 확정 |
| `10% 할인 쿠폰 발송 예정` | 발송과 발급 기준이 불명확함 | `본인 인증 후 멤버십 회원 1인 1회 발급`을 명시 |
| `8/30 기준 멤버십 고객 약 2,600명` | 운영 내부 메모이며 고객 메시지에 불필요 | 외부 메시지와 이미지에서 제거 |
| 쿠폰 버튼 | 현재 이벤트 수령 페이지가 없음 | 이벤트 페이지·OTP·중복 발급 차단 구현 후 연결 |
| 광고 고지 | 프로모션·할인은 광고성 메시지 | `(광고)`, NOPS 연락처, 수신거부 방법을 실제 발송 미리보기에서 확인 |

9월 할인 이벤트는 광고성 브랜드 메시지에 해당한다. 카카오는 광고 표기, 전송자 연락처, 쉽게 가능한 수신거부 방법 표기를 요구하며, 발송 허용 시간은 08:00~20:50 KST다.[4]

## 권장 메시지 초안

### 이미지형 브랜드 메시지 본문

> **(광고) [NOPS] 9월 멤버십 감사 이벤트**  
> 콤보 메뉴 10% 할인 쿠폰을 준비했습니다.  
> 아래에서 본인 인증 후 멤버십 회원 1인 1회로 쿠폰을 받을 수 있습니다.  
> 행사 기간: **[2026.09.DD~2026.09.DD]**  
> 쿠폰 사용 조건과 제외 메뉴는 이벤트 페이지에서 확인해 주세요.  
> 문의: **02-597-4030**  
> 수신거부: **[카카오 채널 차단 경로 또는 확정된 수신거부 방식]**

### 버튼 구성

| 버튼 | 링크 | 목적 |
|---|---|---|
| `쿠폰 받기` | `/event/sep-combo-2026?...` | OTP 인증·대상 확인·쿠폰 1회 발급 |
| `행사 조건` | 이벤트 페이지 내 이용 조건 영역 또는 별도 안내 URL | 적용 메뉴·기간·중복 할인 여부 공개 |
| `채널 추가` | 카카오 채널 추가 링크 | 비친구 유입 시에만 사용 |

## 쿠폰 발급 정책 제안

이벤트 쿠폰은 기존 가입 기념 10% 할인 쿠폰과 분리해야 한다. 기존 쿠폰을 재발급하면 회원당 1회 혜택 정책과 현재 DB 고유 제약을 무너뜨린다. 별도 쿠폰 템플릿과 별도 발급 키를 사용한다.

| 항목 | 제안값 |
|---|---|
| 캠페인 코드 | `sep_combo_2026` |
| 쿠폰명 | `9월 콤보 메뉴 10% 할인 쿠폰` |
| 할인율 | 10% — 현재 CRM은 정수 할인율만 지원하므로 9.9%는 사용 불가 |
| 발급 키 | `sep_combo_2026_v1` |
| 발급 대상 | OTP 인증을 완료한 활성 멤버십 회원 중 기존 캠페인 미수령자 |
| 1회 제한 | 회원 ID + 발급 키 복합 고유 제약 |
| 사용 조건 | 적용 메뉴, 사용 가능 지점, 중복 할인 가능 여부, 유효기간을 이벤트 페이지·쿠폰 상세에 동일하게 표시 |

## 발송 전 필수 결정사항

1. 할인 적용 범위를 `베네핏 스테이크 콤보 전 메뉴` 또는 `전 콤보 메뉴` 중 하나로 확정한다.
2. 행사 기간, 쿠폰 사용 가능 기간, 제외 메뉴·지점, 타 할인 중복 가능 여부를 확정한다.
3. 채널 친구 전체 발송을 카카오 채널 관리자센터에서 실행할지, CRM 수신번호 기반 SOLAPI `I` 타게팅으로 제한할지 결정한다.
4. 이벤트 페이지·OTP·별도 캠페인 쿠폰·발송 이력을 구현하고 테스트한다.
5. 발송 전 실제 카카오 미리보기에서 광고 표기·연락처·수신거부 문구가 노출되는지 확인하고 08:00~20:50 KST에 예약한다.
